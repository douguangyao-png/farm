# 认养农场 SaaS · 四端演示手册

> 演示环境：http://121.40.221.126/farm/ （后台）、/farm/m/ （C 端，用手机打开或浏览器手机模式）、/farm/steward/ （管家端，同上）。
> 账号和每个数字的出处见 `docs/demo/演示数据说明.md`。页面上标「演示数据」的部分（支付、合同签署、直播、IoT、分账、物流）是模拟的。
> 每场演示前建议重置数据：在服务器上执行 `curl -X POST 127.0.0.1:48090/__mock/reset`（公网不开放这个入口）。重置会让所有人退出登录。

建议开三个窗口：电脑浏览器开后台，两个手机模式窗口（Chrome 开发者工具切 iPhone 尺寸）分别开 C 端和管家端。

## 1. 平台开通租户（后台，平台运营中心 / admin / admin123）

1. 「平台管理 → 平台总览」：讲平台视角——租户数、本月 GMV、待处理预警。
2. 「租户列表」→ 新增：填租户名（如「东篱农场」）、联系人、选「专业版」、管理员账号密码 → 保存。讲：开通后经营者用自己的账号登录，数据和别的农场完全隔离。
3. 「风控预警」：看到「绿野农庄」文案出现「年化收益」的高风险预警 → 处理，填说明。

## 2. 经营者发布认养商品（后台，青山农场 / qingshan / demo123）

1. 「经营看板 → 工作台」：GMV 曲线、认养位使用率、待办（2 条农事记录待审核、1 批收成待发货）。
2. 「基地资产 → 地块与畜禽」：A-01 空闲，点「环境数据」看墒情。A-03 的土壤湿度在 19% 左右，低于 22% 阈值，所以管家端会有一条墒情触发的浇水任务。
3. 「认养商品 → 新增」：表单已按「一分菜地」预填三档托管。**先把标题改成「稳赚收益菜地」提交**——被拦截，提示命中「稳赚」「收益」并给出改写建议（R-2）。再改成「一分菜地 · 春季认养」提交成功。讲：全托管写「约定交付 240 斤，不足部分按同等品质补发」，半托管、不托管按实际收成交付；每档绑定不同版本的合同。
4. 「经营看板 → 风险自检」：刚才那次拦截已经计入「文案合规」。

## 3. C 端用户认养（C 端，13800000001 / demo123 周女士）

1. 首页 → 「一分菜地 · 年度认养」→ 三档卡片：全托管 ¥1,280、半托管 ¥860、不托管 ¥500。切换时责任划分、产出说明、合同版本跟着变；点「托管方式对比」看 13 项农事谁来做。
2. 选**半托管** → 立即认养 → 确认订单。**不勾合同直接点支付：被拦住**，提示先阅读并勾选合同（R-3）。勾选 → 支付（演示支付，不扣款）→ 结果页显示分到地块 A-01。
3. **切到后台「认养订单」**：最上面就是这一单，半托管、A-01、合同 v2.1。点进详情看认养关系（主线第 4 步）。

## 4. 管家打卡 → 审核 → C 端档案（主线第 5、6 步）

1. 管家端（青山农场 / zhangguanjia / demo123）：工作台有 A-03 浇水（墒情触发）、A-01 新认养交接等任务。
2. 打开 A-03 浇水 → 去打卡 → 拍照（演示环境可点「使用演示照片」）→ 提交。结果页显示三项机器校验：拍摄时间、GPS 围栏、重复画面。
3. 后台「农事代管 → 农事记录审核」：这条在待审核里，带照片、环境快照和校验结果 → 通过。
4. C 端「认养」→ A-03（周女士的全托管地块）→ 生长档案多了刚才这条；再看溯源六段、环境数据曲线、监控画面（视频占位）。

## 5. 自管任务逾期 → 委托代办（主线第 7 步，R-5）

1. C 端「认养」→ A-05（半托管）→ 自管任务：「浇水」已逾期，红色标出。
2. 点「委托管家代办 ¥15」→ 确认 → 提示工单号。
3. 管家端「代管工单 → 工单池」：出现这张待接单工单 → 接单 → 工作台多一条「代管工单」任务 → 打卡完成。
4. 后台「代管工单」：状态已完成，分账规则管家 70% / 农场 20% / 平台 10%（演示阶段只展示，不执行）。

## 6. 农资商城（主线第 8 步）

1. C 端「农资」→ 肥料 → 腐熟羊粪有机肥 → 购买：**必须选用在哪块地**（不选会被拦）→ 选 A-05、寄存基地 → 下单。讲：化学农药在商城里根本看不到，只能由农场代施。
2. 后台「农资商城 → 农资订单」：出现这一单，「待登记」→ 登记施用时间和用量 → 变「已写入」，C 端溯源的投入品清单里出现「认养人自购」这一条。

## 7. 收成与配送（主线第 9 步）

1. 后台「订单履约 → 收成录入」：A-04 有一批 12 斤待发货；也可以新增一条收成。
2. 「配送批次 → 新增」：选这批收成、填承运商和单号 → 运输中，自动生成物流轨迹 → 确认签收。
3. C 端（13800000002 陈先生）「认养」→ A-04 → 收获配送：看到物流信息。周女士的 A-03 已有一单签收记录可以直接看。

## 8. 收尾：问题反馈和项目文档

- 任意后台页面右侧「问题反馈」：选类型、写内容、Ctrl+V 粘贴截图 → 提交得到编号 FB-0002。admin 登录「系统管理 → 问题反馈」看到并回复。
- admin「系统管理 → 项目文档」：需求（PRD）、设计（接口契约、ER）、方案与任务、原型都能在线看。

## 9. 租户隔离（R-6，可选）

绿野农庄（lvye / demo123）登录后台：订单、商品、文章、反馈都只有绿野自己的，看不到青山农场的任何数据。
