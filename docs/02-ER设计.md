# 认养农业 SaaS · 数据库 ER 设计

> 设计原则：多租户（所有业务表带 `tenant_id` 行级隔离）；资产/商品/订单解耦；生长档案与 IoT 数据分离（时序库）。
> 配套示意图见 `02-ER.svg`。

---

## 核心实体关系

```
tenant 1──N farm_base 1──N asset
farm_base 1──N product 1──N order ──1──1 adoption ──N──1 asset
member 1──N order
adoption 1──N growth_record ← steward 1──N
order 1──1 shipment ; order 1──N payment
```

---

## 数据表清单（关键字段）

### tenant 租户
| 字段 | 类型 | 说明 |
|---|---|---|
| id | bigint PK | 租户 ID |
| name | varchar | 经营者名称 |
| plan | varchar | 套餐：basic/pro/flagship |
| expire_at | datetime | 到期时间 |
| status | tinyint | 审核/启用/停用 |

### farm_base 基地
| 字段 | 类型 | 说明 |
|---|---|---|
| id, tenant_id | bigint | 基地 / 租户 |
| name, address, geo | varchar | 名称、地址、经纬度 |
| cert_no | varchar | 经营/防疫资质编号（合规核验） |

### asset 认养资产（统一表，按类型区分）
| 字段 | 类型 | 说明 |
|---|---|---|
| id, tenant_id, base_id | bigint | 资产/租户/基地 |
| asset_type | varchar | plot 地块 / animal 畜禽 / tree 果树 |
| code | varchar | 二维码/耳标（绑定认养人） |
| specs | json | 面积/品种/数量等 |
| iot_device_id | bigint | 关联设备（可空） |

### product 认养商品
| 字段 | 类型 | 说明 |
|---|---|---|
| id, tenant_id, base_id | bigint | 商品/租户/基地 |
| asset_type | varchar | 关联资产类型 |
| title, price | varchar/decimal | 标题、认养价 |
| cycle_days | int | 种养周期 |
| yield_rule | text | 产出承诺（实物，禁收益类文案） |
| stock, sold | int | 可售/已售 |

### member 认养用户
| 字段 | 类型 | 说明 |
|---|---|---|
| id, tenant_id | bigint | 用户/租户 |
| openid, phone | varchar | 微信 openid、手机号 |
| level, source | varchar | 等级、来源渠道 |

### order 订单
| 字段 | 类型 | 说明 |
|---|---|---|
| id, tenant_id, member_id, product_id | bigint | 订单/租户/用户/商品 |
| amount | decimal | 金额 |
| pay_status | tinyint | 支付状态 |
| contract_id | bigint | 关联电子合同 |

### adoption 认养关系
| 字段 | 类型 | 说明 |
|---|---|---|
| id, order_id, tenant_id, member_id | bigint | 关系/订单/租户/用户 |
| asset_id, asset_type | bigint/varchar | 绑定实体 |
| start_at, end_at, status | datetime/tinyint | 起止、状态 |

### steward 管家
| 字段 | 类型 | 说明 |
|---|---|---|
| id, tenant_id, base_id | bigint | 管家/租户/基地 |
| name, phone | varchar | 姓名、电话 |

### growth_record 生长档案
| 字段 | 类型 | 说明 |
|---|---|---|
| id, tenant_id, adoption_id, steward_id | bigint | 档案/租户/认养/管家 |
| type | varchar | 农事/图片/视频 |
| content, geo | text/varchar | 内容、定位 |
| created_at | datetime | 时间 |

### iot_device / sensor_data 设备与传感
| 表 | 关键字段 | 说明 |
|---|---|---|
| iot_device | id, asset_id, device_type(cam/sensor/gps), status | 设备（存业务库） |
| sensor_data | device_id, metric, value, ts | 时序库（TDengine），高频写入 |

### shipment 发货 / payment 支付 / settlement 分账 / contract 合同 / distributor 分销
| 表 | 关键字段 | 说明 |
|---|---|---|
| shipment | order_id, adoption_id, logistics_no, carrier, signed_at | 物流履约 |
| payment | order_id, amount, channel, paid_at | 支付流水 |
| settlement | order_id, merchant_amount, platform_fee, settled_at | 分账结算 |
| contract | order_id, template_id, signed_at, file_url | 电子合同（对接 e签宝/法大大） |
| distributor | tenant_id, parent_member_id, order_id, commission | 分销佣金 |

### 托管模式与农资商城（2026-10-13 增补）
| 表 | 关键字段 | 说明 |
|---|---|---|
| care_mode_config | sku_id, mode(full/semi/self), price_delta, duty_matrix(JSON), output_promise, contract_tpl_id, supply_package | 托管模式配置，一个 SKU 三档各一行 |
| supply_spu | tenant_id, cat(seed/fert/tool/bio/svc/ins), price, cost, stock, fit_modes, batch_no, retail_allowed, need_workorder | 农资/服务商品；化学农药 retail_allowed=0 |
| supply_order | adoption_id, land_id, sku_id, qty, amount, deliver_way, trace_state | 农资订单，**必须绑定地块** |
| input_record | land_id, source(farm/customer), name, batch_no, used_at, dosage, operator | 投入品台账，两来源合并进溯源 |
| task_template | crop_id, stage, trigger(crop_calendar/iot_threshold/manual), trigger_rule, owner(keeper/customer), overdue_action | 任务模板与触发规则 |
| service_order | land_id, customer_id, keeper_id, service_type, price, split_rule, proof_photos, status | 代管服务工单，分账 70/20/10 |

> 关系要点：`care_mode_config.duty_matrix` 决定 `task_template.owner`；owner=customer 的任务推送到 C 端自管任务，逾期生成 `service_order`；`supply_order` 与 `input_record` 通过 land_id + batch_no 关联，共同写入溯源档案。

## 索引与性能要点
- 所有业务表以 `tenant_id` 为前缀复合索引，保证隔离与查询效率
- `order(product_id, pay_status)`、`adoption(asset_id)`、`sensor_data(device_id, ts)` 建索引
- 传感高频数据走时序库，按 device_id 分片，热数据保留 30 天
- 媒体（视频/图片）存对象存储，DB 仅存 URL
