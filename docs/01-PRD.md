# 认养农业 SaaS 系统 · 产品需求文档（PRD）

> 版本：v0.1 ｜ 定位：面向认养农业 / 共享农场经营者的多租户数字化经营中台（B2B2C）
> 核心价值：① 沉淀自万级项目的标准化运营 SOP；② 真透明（IoT+直播+溯源）建立信任；③ 合规内置规避非法集资红线。

---

## 1. 产品概述

| 项 | 内容 |
|---|---|
| 产品定位 | 认养农业"操作系统"——经营者开通租户即用，服务其自有认养客户 |
| 目标客户 | 家庭农场、农民合作社、区域农业企业、文旅农庄、研学基地 |
| 商业模式 | SaaS 订阅 + 交易抽成 + 实施/定制费 + 硬件/保险分润 |
| 关键差异化 | 合规内置（对公收款/电子合同/分账/保险）、真透明（IoT+直播溯源）、小微低成本上手 |

---

## 2. 用户角色与权限

| 角色 | 身份 | 关键诉求 |
|---|---|---|
| 平台运营（我们） | 系统提供方 | 多租户管理、计费、风控合规、模板沉淀 |
| 租户-经营者 | 农场主/合作社管理员 | 卖认养、管基地、管客户、看经营数据 |
| 管家 | 田间运营人员 | 农事打卡、客户跟进、发货上报 |
| 认养用户（C 端） | 消费者 | 认养、看生长、收产出、互动、复购 |
| 分销团长 | 社群/KOL/村播 | 推广赚佣金 |

权限模型：平台运营 > 经营者（租户管理员）> 子账号（经营/管家/财务，按角色授权）。所有数据严格 tenant_id 隔离。

## 3. 功能模块

### 3.1 消费者小程序 / H5
- **认养商城**：按品类（地/鸡/果树/牛羊）浏览商品卡（价格、周期、产出承诺、剩余库存）
- **商品详情**：基地介绍、实时监控入口、往期评价、合规风险提示
- **认养下单**：选规格 → 签电子合同 → 支付（支持分期）
- **我的认养**：绑定专属实体（地块二维码 / 畜禽耳标），查看专属档案
- **实时监控**：直播流 + IoT 数据（温湿度/定位/活动量）
- **生长档案**：时间轴展示每次农事记录（图文/视频）
- **溯源查询**：种养 → 加工 → 配送全链路可查
- **收获与配送**：自提/快递切换、冷链追踪、签收确认
- **社区/农场日记**：动态、互动、认养转赠好友
- **会员与复购**：储值、续费、老带新

### 3.2 经营者后台（Web）
- **租户与权限**：子账号、角色（经营/管家/财务）
- **基地管理**：基地、地块、畜禽、果树数字化台账（含二维码/耳标生成打印）
- **商品配置**：认养套餐（价格、产出规则、周期、可售库存）
- **订单管理**：认养确认、退款、合同管理
- **农事管理**：任务派发、管家打卡、记录审核
- **IoT 管理**：设备接入、资产绑定、异常告警
- **履约配送**：发货、物流对接、签收确认
- **CRM**：认养人画像、复购、分层、企微触达
- **营销中心**：拼团、优惠券、分销团长、直播带货
- **财务中心**：收款对账、分账、发票、经营看板
- **内容中心**：农场日记发布、素材库

### 3.3 管家 App / 企微
- 任务看板（今日农事）
- 一键打卡：拍照/视频 + 定位 + 选择关联认养
- 客户跟进：认养人消息、关怀提醒
- 发货上报

### 3.4 平台管理端
- 租户审核 / 开通 / 停用
- 计费与账单
- 风控合规监控（异常预警：虚构基地、刷单、超范围经营、承诺收益）
- 模板库（合同/套餐/话术/海报）
- 全局数据总览

---

## 4. 核心业务流程

1. **认养下单**：浏览 → 下单 → 签电子合同 → 支付 → 生成认养关系 + 绑定实体 → 管家接单
2. **农事记录**：管家打卡 → 生成生长记录 → 推送用户时间轴 → 累积溯源链
3. **履约交付**：到期/产出 → 打包 → 物流 → 签收 → 订单完成
4. **分账结算**：用户支付入平台商户号 → 按规则分账给经营者 + 平台抽成 → 出具账单/发票

---

## 5. 关键业务规则（合规底线）

- 产出以**实物交付**为终，系统禁止配置任何"固定现金收益/返利"类文案（防非法集资）
- 电子合同必须明确：认养对象、数量、发货时间、违约责任
- 收款走**对公/平台商户号**，禁止引导私人账户（系统层面禁用个人收款码配置）
- 农业保险建议对接，覆盖疫病/自然灾害造成的履约风险
- 退款规则：未启动种养可退；种养中按已发生成本比例退

## 6. 非功能需求

- **多租户**：数据 tenant_id 行级隔离 + 可选独立 schema；资源配额限流
- **安全**：HTTPS、敏感数据脱敏、权限最小化、操作审计日志
- **性能**：列表/详情 < 500ms；直播端到端延迟 < 2s；支持万级并发认养
- **合规**：等级保护、个人信息保护、电子合同法律效力（对接 e签宝/法大大）
- **可观测**：日志、监控、告警、业务埋点

---

## 7. 埋点与核心指标

- **经营者侧**：认养率、GMV、复购率、客单价、履约准时率、管家打卡率
- **用户侧**：小程序打开率、监控观看时长、生长档案互动率、复购转化率
- **平台侧**：租户活跃率、ARPU、抽成收入、合规预警命中数

## 8. 增补模块：托管模式与农资商城（2026-10-13 新增）

土地认养商品支持 **全托管 / 半托管 / 不托管** 三档，配合农资与服务商城，构成"低门槛获客 + 高频复购 + 降本增毛利"的组合。

- **核心规则**：参与越多认养费越低，责任边界同步收紧，合同按模式分版本（v3.2 / v2.1 / v1.4）
- **任务引擎**：农事任务按"责任矩阵"自动分流给管家或认养人；自管任务逾期自动转"委托代办"工单并分账（管家 70% / 农场 20% / 平台 10%）
- **农资商城**：种子 / 肥料 / 农具 / 生物防治 / 代管服务 / 保险六类，强制绑定地块、批次留痕、投入品台账合并展示；**化学农药禁止对个人零售**
- **三端改动与详细数据模型见 `10-托管模式与农资商城设计.md`**
