## 5. T4 执行记录（2026-11-07，对 121 服务器的改动与回滚）

数据库定为 PostgreSQL（用户 2026-11-07 选择；系统源里没有真正的 MySQL）。芋道自带 `sql/postgresql` 建表脚本。

| 改动 | 验证 [实测] | 回滚 |
|---|---|---|
| 新建 PostgreSQL 账号 `farm`（连接数上限 15）和独立库 `farm`；口令在 `/opt/farmer-saas/backend/db.env`（权限 600） | farm 账号能连 farm 库；training、ziheng_biz、ziheng_review、osce 四个库仍可连 | `su - postgres -c "psql -c 'DROP DATABASE farm; DROP ROLE farm;'"` |
| `pg_hba.conf` 末尾追加 farm/farm 两行（127.0.0.1、::1，scram-sha-256），备份 `pg_hba.conf.bak-20261107`，reload | reload 后 training、ziheng-biz、ziheng-review 服务仍 active | `cp /var/lib/pgsql/data/pg_hba.conf.bak-20261107 /var/lib/pgsql/data/pg_hba.conf && systemctl reload postgresql` |
| `dnf install java-21-openjdk-devel maven`（Maven 3.6.3 连带装了 JDK 17，Maven 用 17 编译，与芋道 master-jdk17 一致）；装后把系统默认 java / javac 用 `alternatives --set` 还原为 21 | `java -version` 21.0.13、`javac` 21.0.13；training / ziheng-biz / ziheng-review 用写死的 JRE 路径，本来就不受影响 | `dnf remove java-21-openjdk-devel maven java-17-openjdk-headless`，再 `alternatives --auto java` |

Redis：不用服务器上已有的 6379（带密码，别的系统在用）；真后端用独立实例（6380），部署时再建，建前再报告。
后端服务端口 48080，现有 mock 48090 保持不动，最后一步才切 nginx。
