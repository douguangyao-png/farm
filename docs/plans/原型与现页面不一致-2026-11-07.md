方法：[实测] 本机起 mock-server + web-admin（mock 模式），浏览器登录 qingshan，与原型 08 逐页并排看；菜单对照用 mock-server/seed/menus.json。
只并排看了「工作台」「认养订单」两页的渲染；其它页只比了菜单和字段，C 端、管家端本次没有逐页看渲染。

## A. 导航（原型 34 页 vs 现有）
| 原型页 | 现状 |
|---|---|
| 工作台、认养商品、认养订单、订单详情、合同管理、收成录入、配送批次、农资订单、代管服务工单、风险自检 | 有 |
| 地块资产 / 畜禽资产 | 合成一个「地块与畜禽」页，无畜禽批次、产蛋、损耗 |
| 发布认养商品 | 未单列菜单（在商品页内），未核对表单是否一致 |
| 农事记录发布 | 现为「农事记录审核」，名称和入口不同 |
| 农资与服务商品 | 现为「农资商品」，没有「服务商品」 |
| 套餐与租户、角色权限 | 在平台管理 / 系统管理里，形态是芋道原版，不是原型样式 |

| 分组 | 原型 6 组（经营看板/商品与资产/托管·农资/订单与履约/内容与监控/客户与人力…），现为 8 组，名称和归属不同 |

## B. 外观（[实测]，只看了两页）
1. 侧边栏：原型深绿底，菜单带红色待办数字角标（认养订单 2、合同 1、退款 2…）；现为深蓝黑底、无角标。
2. 顶栏：原型是「租户名 + 切换租户 + 告警数」；现为芋道原版工具栏（搜索、字号、语言、消息、租户下拉）。
3. 页面外框：原型是卡片式、页面标题加面包屑；现为芋道的标签页 + 面包屑。
4. 工作台：卡片、待办、曲线、认养位使用、最新订单的结构一致；差别是曲线（原型折线较平，现为平滑曲线）、原型待办条目带数量徽标样式不同、认养位使用的数字是演示规模（826/1000 vs 3/7）。
5. 认养订单：页签+数量、筛选、列、履约进度条、状态标签与原型一致；多一列「托管方式」，原型没有；筛选项多出手机号、托管方式；原型底部有绿色分账提示条，现为灰色小字说明；原型是 6 条示例，现为实际数据（订单号格式 RY2026… vs A2026-…）。

## C. 第一期留下的缺口
订单详情：来源渠道、所选套餐/含券、GPS、客户标签；「交付方式」没落库；配送「批次」实体；收成环境快照；退款闭环。
