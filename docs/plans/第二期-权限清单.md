# 第二期权限清单

各小节由各 agent 自己追加。UI 小节为「菜单与分组」。

## 菜单与分组（UI）
来源：`mock-server/seed/menus.json`（`deploy/tools/gen-farm-seed.py` 转成 `farm-seed.sql`，真后端菜单 id 加 100000 偏移；带 permission 的行生成为按钮，type=3）。

规则：
- 页面菜单 path 即路由段，组件 `farm/<dir>/index`，组件名见下表（页面 `defineOptions({ name })` 请与之一致，keepAlive 才生效）。
- 按钮权限串 `farm:<dir去横线>:<动作>`。mock 里 `*:*:*` 恒有，真后端按角色授权。
- 角色授权：经营者（tenant_admin，租户 2、3）= 除「平台管理」「字典」「项目文档」外的全部页面和按钮；平台管理员（super_admin）= 平台管理 + 系统管理 + 内容运营（文章/分类）；管家（steward）走管家端，后台菜单为空。租户套餐三档的菜单与经营者一致。
- 现有页面（第一期及以前）没有按钮权限串，沿用「页面可见即可操作」；只为第二期新页建按钮。

### 路径变化（旧 -> 新），硬编码跳转需同步
- 认养商品 `/farm-product/product` 不变；基地 `/farm-asset/base`、地块 `/farm-asset/asset` -> `/farm-product/base`、`/farm-product/asset`（工作台已改）。
- 代管工单 `/farm-work/service-order` -> `/farm-supply/service-order`；农资商品、农资订单 `/farm-supply/*` 不变。
- 风险自检 `/farm-board/self-check` -> `/farm-compliance/self-check`。
- 文章、分类 `/system/article`、`/system/article-category` -> `/farm-work/article`、`/farm-work/article-category`（菜单名「内容运营」「文章分类」）。
- 工作台待办 todos 里的 path 已同步（mock 与 Java 两处）。其它页面请只引用上表的新路径。
- 订单页 `/farm-order/order`、`/farm-order/harvest|shipment|contract` 不变；退款审核 `/farm-order/refund`。

### 侧栏角标与顶栏
- 角标取自 `/farm/dashboard/summary` 的 `todos`，按 todo.path 与菜单完整路径相等匹配（`web-admin/src/store/modules/farmNav.ts`）。要给新页加角标，在 todos 里加一条 path 等于该页完整路径的待办即可。
- 顶栏右侧：租户名（`/system/tenant/simple-list` 按当前租户取名）+ 告警数（经营者 = 待办总数，平台 = `pendingAlertCount`）。
