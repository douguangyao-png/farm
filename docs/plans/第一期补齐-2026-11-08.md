## 接口约定（admin = /admin-api/farm，app = /app-api/farm；响应均 {code,data,msg}）
1. **订单补字段**（orders 表加列，DO/Mapper/mock 同步）：
   `channel`(来源渠道 varchar16: mini/h5/scan/steward)、`packageName`(所选套餐 varchar64)、`couponName`(varchar64)、`couponAmount`(分 int8,默认0)、`gpsLng`/`gpsLat`(numeric(10,6) 可空)、`gpsText`(varchar128 可空)、`deliverWay`(varchar16: express 快递到家/pickup 到基地自提/farm_deliver 基地配送)。
   - app `POST /order/create` 入参增加可选 `deliverWay, channel, packageName, lng, lat, gpsText`；缺省 channel=h5、deliverWay=express。
   - admin `GET /order/get` 响应增加以上字段 + `customerTags: string[]`（由客户分层/复购/认养数派生，不落库；复用 FarmCustomer 派生逻辑）。`order/page` 行增加 channel、deliverWay。
2. **配送批次**（新表 farm_ship_batch：id,no(PC20261108001),harvest_id,plan_date,status(0待发/10已发出/20已完成),remark,通用列）；`farm_shipment` 加 `batch_id`。
   admin：`GET /ship-batch/page`(pageNo,pageSize,status)、`GET /ship-batch/get?id`(含 shipments[])、`POST /ship-batch/create {harvestId,planDate,remark?,shipmentIds[]}`、`PUT /ship-batch/ship {id}`(批次下配送单全部置已发出，只允许 status=0)、`PUT /ship-batch/finish {id}`(只允许 10)。错误：批次不存在 404，状态不对 400。
3. **收成环境快照**：farm_harvest 加 `env_snapshot text`(JSON：{temp,humidity,soilMoisture,light,capturedAt,source:'演示数据'})。创建收成时按该资产当前环境数据（FarmAssetService 的环境生成函数）写入。admin `harvest/get|page` 与 app 收成详情返回 `envSnapshot`。
4. **畜禽批次**（新表 farm_livestock_batch：id,no(XB20261108001),base_id,species,breed,in_date,count,out_count,status(0在栏/10出栏中/20已出栏),pen,remark,通用列）。admin：`GET /livestock-batch/page`(species,status)、`GET /livestock-batch/get`、`POST /livestock-batch/create`、`PUT /livestock-batch/update`、`PUT /livestock-batch/out {id,count}`(出栏：out_count 累加，不超过 count，满额置 20)、`DELETE /livestock-batch/delete`(仅 out_count=0)。种子：青山农场 2 批，绿野农庄 1 批。
5. **契约文档**：把第二期 + 本次全部新接口补进 `docs/api/farm-接口契约.md`（登记在 docs/plans/第二期-登记/*.md 里的内容汇总过来）。
6. **菜单**：新增独立菜单「发布认养商品」(路径 `/farm-product/product-create` → 复用商品编辑页的新建态)、「配送批次」(farm-fulfill/ship-batch)、「畜禽批次」(farm-product/livestock-batch)，权限串 farm:shipbatch:*、farm:livestockbatch:*。
7. **租户切换**：平台管理员（tenantId=1）顶栏下拉选租户，选后后续请求带 `visit-tenant-id` 头；mock 与 Java 都要支持该头（平台管理员才生效）。其它角色不显示。
8. **按钮权限**：第一期已有页面（商品、订单、认养、任务、收成、配送、合同、内容等）的新增/编辑/删除/导出/审核等按钮补 `v-hasPermi`，权限串与 farm-seed.sql 里已有菜单按钮一致。
9. **C 端**：首页金刚区(10 项,配置在前端常量)+秋播横幅；合同独立页(`pages/farm/contract/detail`，含手写签名 canvas，签名图片存 `/app-api/farm/contract/sign`)；确认订单页「交付方式」三选一并传 deliverWay；农资独立结算页；地址选择模式接到确认订单页；退款状态标签按 refund 状态码 0待审核/10已同意/20已驳回 显示。
