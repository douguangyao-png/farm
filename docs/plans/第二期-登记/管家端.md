## ② 建表 SQL（PostgreSQL，追加到 farm.sql；DROP 清单也要加这三张）

```sql
CREATE SEQUENCE farm_steward_alarm_seq START 1000 INCREMENT 1;
CREATE SEQUENCE farm_steward_message_seq START 1000 INCREMENT 1;
CREATE SEQUENCE farm_steward_remind_seq START 1000 INCREMENT 1;

-- 管家异常上报（设备异常 / 损耗登记 / 气象灾害 / 病虫害爆发）
CREATE TABLE farm_steward_alarm (
  id int8 PRIMARY KEY, steward_id int8 NOT NULL, type varchar(16) NOT NULL, level varchar(4) NOT NULL DEFAULT '中', asset_id int8,
  title varchar(200) NOT NULL, content text DEFAULT '', qty int4, photos text DEFAULT '[]', insurance_reported bool NOT NULL DEFAULT false, status int2 NOT NULL DEFAULT 0,
  creator varchar(64) DEFAULT '', create_time timestamp NOT NULL DEFAULT CURRENT_TIMESTAMP, updater varchar(64) DEFAULT '',
  update_time timestamp NOT NULL DEFAULT CURRENT_TIMESTAMP, deleted int2 NOT NULL DEFAULT 0, tenant_id int8 NOT NULL DEFAULT 0
);
-- 管家与认养人聊天
CREATE TABLE farm_steward_message (
  id int8 PRIMARY KEY, steward_id int8 NOT NULL, member_id int8 NOT NULL, asset_id int8, sender varchar(16) NOT NULL, content varchar(1000) NOT NULL,
  creator varchar(64) DEFAULT '', create_time timestamp NOT NULL DEFAULT CURRENT_TIMESTAMP, updater varchar(64) DEFAULT '',
  update_time timestamp NOT NULL DEFAULT CURRENT_TIMESTAMP, deleted int2 NOT NULL DEFAULT 0, tenant_id int8 NOT NULL DEFAULT 0
);
CREATE INDEX idx_farm_steward_message_pair ON farm_steward_message (steward_id, member_id, create_time);
-- 自管提醒记录（哪条自管任务已被管家提醒 / 推送过委托代办）
CREATE TABLE farm_steward_remind (
  id int8 PRIMARY KEY, steward_id int8 NOT NULL, task_id int8 NOT NULL, entrust bool NOT NULL DEFAULT false, remind_time timestamp NOT NULL DEFAULT CURRENT_TIMESTAMP,
  creator varchar(64) DEFAULT '', create_time timestamp NOT NULL DEFAULT CURRENT_TIMESTAMP, updater varchar(64) DEFAULT '',
  update_time timestamp NOT NULL DEFAULT CURRENT_TIMESTAMP, deleted int2 NOT NULL DEFAULT 0, tenant_id int8 NOT NULL DEFAULT 0
);
```

对应 Java：`FarmStewardAlarmDO / FarmStewardMessageDO / FarmStewardRemindDO` 与三个 Mapper（已新增）。

## ③ 契约接口表（追加到 docs/api/farm-接口契约.md 第 3 节之后）

前缀 `/admin-api/farm/steward`，要管家账号；一律只能看、只能做 `farm_adoption.steward_id = 当前账号` 的认养。别人的认养返回 1_030_000_007。

| 方法 路径 | 入参 | 返回 | 说明 |
|---|---|---|---|
| GET /shipment/list | status? (0 待发货 / 10 已发货 / 20 已签收) | `{ stats:{pending,shipped,done}, pending:[{harvestId,crop,weightJin,harvestDate,remark,assetCode,memberName}], list:[配送单视图] }` | pending = 我负责、未发货的收成；status 非 0 时 pending 为空，=0 时 list 为空 |
| POST /shipment/create | harvestId, carrier, logisticsNo, coldChain? | 配送单 id | 口径同后台 `POST /farm/shipment/create`，多一层「收成属于我负责的认养」 |
| PUT /shipment/sign | id 或 no | true | 自提核销 / 签收；只有运输中（10）能签；no = 扫码得到的配送单号 |
| GET /self-guide/list | state? todo/reminded/over（默认 todo） | `{ stats:{plots,weekTodo,reminded,overdue}, counts:{todo,reminded,over}, list:[{taskId,assetCode,memberId,memberName,careModeName,title,description,deadline,state,entrustPrice,remindedAt}] }` | 数据 = 我负责认养下 owner=member 的任务；state：todo 需提醒、reminded 已提醒未做、over 已逾期、done |
| POST /self-guide/remind | taskId, entrust? | true | 记提醒并给认养人发一条聊天消息；entrust=true 为「推送委托代办」（只发消息，不自动建工单，认养人在 C 端点委托才建） |
| GET /record/list | status? | `{ stats:{all,pending,published,rejected}, list:[记录视图+assetCode] }` | 我提交的记录，最多 100 条 |
| GET /asset/list | scope? all/raising/free | `{ counts:{all,raising,free}, list:[{id,code,name,assetType,crop,areaM2,raising,statusName,memberName,mine,progress,harvestedJin,promisedJin,leftDays}] }` | 范围 = 我所在基地的标的；mine 表示是否我负责 |
| GET /supply-task/list | tab? todo/done | `{ counts:{todo,done}, list:[{id,no,assetCode,memberName,supplyName,cat,batchNo,kind,careModeName,hint,done,usedAt,dosage}] }` | 我负责认养下的农资订单，排除保险(ins)和服务(svc)类 |
| PUT /supply-task/apply | id, dosage, usedAt? | true | 登记施用/安装，写投入品台账（source=farm）；口径同后台 `PUT /supply-order/trace` |
| GET /alarm/list | - | `[{id,type,level,assetCode,title,content,qty,photos,insuranceReported,createTime}]` | 我上报的 |
| POST /alarm/create | type(设备异常/损耗登记/气象灾害/病虫害爆发), content, assetId?, qty?, photos? | id | 非「设备异常」必须有照片；损耗必须填数量；assetId 须属于本基地。保险报备只是演示标记，没有对接保险 |
| GET /message/conversations | - | `{ list:[{memberId,memberName,assetCode,last,lastTime,unread}], notices }` | 我负责的在养认养人 |
| GET /message/list | memberId | `{ member:{id,name,mobile(脱敏),assetCode}, list:[{id,from,content,createTime}] }` | 非我负责的认养人返回 1_030_000_007 |
| POST /message/send | memberId, content | true | 内容 1～500 字 |
| GET /performance | - | `{ month, assetCount, memberCount, monthCheckins, completionRate, passRate, outputRate, responseMinutes, satisfaction, score }` | completionRate = 本月到期的管家任务里按时完成占比；responseMinutes、satisfaction、score 系统无数据，恒为 null，前端显示「暂无数据」 |

没有新错误码，沿用 1_030_000_002/006/007 与 400/403/404。

## ④ 测试用例（可粘贴到 test/farm.test.ts，沿用该文件已有的 get/post/put 辅助与管家登录 `s`；种子里管家 `s` 负责的认养至少一条）

```ts
describe('管家端补充（第二期）', () => {
  it('配送确认：只能处理自己负责的认养；发货、核销走通', async () => {
    const list = await get('/admin-api/farm/steward/shipment/list', s)
    expect(list.code).toBe(0)
    expect(list.data.stats).toHaveProperty('pending')
    const h = list.data.pending[0]
    if (h) {
      expect((await post('/admin-api/farm/steward/shipment/create', s, { harvestId: h.harvestId, carrier: '', logisticsNo: 'X' })).msg).toBe('请填写承运商')
      const c = await post('/admin-api/farm/steward/shipment/create', s, { harvestId: h.harvestId, carrier: '顺丰冷链', logisticsNo: 'SF100' })
      expect(c.code).toBe(0)
      expect((await put('/admin-api/farm/steward/shipment/sign', s, { id: c.data })).code).toBe(0)
      expect((await put('/admin-api/farm/steward/shipment/sign', s, { id: c.data })).code).toBe(1_030_000_002)
    }
    // 另一个管家不能操作
    const other = await post('/admin-api/farm/steward/shipment/create', li, { harvestId: h?.harvestId ?? 1, carrier: 'a', logisticsNo: 'b' })
    expect(other.code).not.toBe(0)
  })
  it('异常上报：灾害必须留影像；损耗必须填数量', async () => {
    expect((await post('/admin-api/farm/steward/alarm/create', s, { type: '气象灾害', content: '冰雹' })).msg).toBe('损耗、灾害、病虫害必须留现场影像')
    expect((await post('/admin-api/farm/steward/alarm/create', s, { type: '损耗登记', content: '死亡', photos: ['x'] })).msg).toBe('请填写损耗数量')
    expect((await post('/admin-api/farm/steward/alarm/create', s, { type: '设备异常', content: '摄像头离线' })).code).toBe(0)
    const l = await get('/admin-api/farm/steward/alarm/list', s)
    expect(l.data.length).toBeGreaterThan(0)
  })
  it('聊天：只能和自己负责的认养人聊', async () => {
    const cv = await get('/admin-api/farm/steward/message/conversations', s)
    expect(cv.code).toBe(0)
    if (cv.data.list[0]) {
      const mid = cv.data.list[0].memberId
      expect((await post('/admin-api/farm/steward/message/send', s, { memberId: mid, content: '你好' })).code).toBe(0)
      expect((await get('/admin-api/farm/steward/message/list', s, { memberId: mid })).data.list.at(-1).content).toBe('你好')
    }
    expect((await post('/admin-api/farm/steward/message/send', s, { memberId: 999999, content: 'x' })).code).toBe(1_030_000_007)
  })
  it('只读接口都能返回，非管家 403', async () => {
    for (const p of ['self-guide/list', 'record/list', 'asset/list', 'supply-task/list', 'performance']) {
      expect((await get(`/admin-api/farm/steward/${p}`, s)).code).toBe(0)
      expect((await get(`/admin-api/farm/steward/${p}`, h)).code).toBe(403)
    }
  })
})
```

（`li`、`h` 是 farm.test.ts 里现有的另一管家 / 非管家会话变量名，粘贴时按文件里实际名字调整。）
